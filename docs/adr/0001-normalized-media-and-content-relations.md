# Normalize media assets and content relations

The application will represent uploaded and generated objects as lifecycle-managed media assets, releases and playlists as separate ordered collection concepts, and likes/reposts as concrete per-content relations. Intrinsic audio metadata is stored in `AudioAnalysis`, and durable `MediaProcessingJob` records drive out-of-request waveform generation. This replaces embedded storage fields and waveform JSON, dummy duration values, boolean privacy, direct album membership, and nullable polymorphic reactions so ownership and relational invariants are enforceable by the database instead of application convention.
